Week 1 – First LLM API Call Using OpenAI

In Week 1, I built my first Python application that communicates with OpenAI's Large Language Model (LLM). I used the OpenAI API to send a question and retrieve an AI-generated answer.

**Implementation Process:**
- Set up the project using the existing Python virtual environment.
- Configured an API key through a `.env` file.
- Installed the OpenAI SDK and required dependencies.
- Initialized the OpenAI client in Python.
- Sent prompts to the AI model using the Responses API.
- Retrieved and displayed the generated output in the terminal.

**Commands Executed:**
```bash
cd week1-llm-call
python -m pip install -r requirements.txt
python main.py
```

**Outcome:** Successfully established communication between Python and OpenAI and generated responses by providing different prompts.
